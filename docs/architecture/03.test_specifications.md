## 1. Test Strategy & Verification Pyramid

To achieve 100% test coverage across the smart mixer appliance, tests are categorized into 4 execution tiers across the CI/CD pipeline:

```text
               / \
              /   \      Tier 4: Physical HIL (Nightly on NXP RW610 Test Jig)
             / HIL \     - Real silicon, physical JTAG, actual motor & current draw
            /-------\
           / Renode  \   Tier 3: Peripheral & System Emulation (PR Merge Gate)
          / Virtual   \  - Full PCB: 11 slider GPIOs, soft-start ramping, thermal cutoff
         /-------------\
        /  QEMU Smoke   \ Tier 2: Kernel & Scheduler Gate (Every Commit, <3s)
       /   Simulation    \- RTOS boot, thread creation, message queue IPC
      /-------------------\
     /   Unit & Logic     \ Tier 1: Host / Native Logic Tests (Static Analysis & Zephyr ztest)
    /     State Machine    \- Pure C state transitions, ramping math, boundary limits
   /-------------------------\
```

## 4. Test Suite 3: Anti-Flour-Splash Soft-Start & Deceleration Ramping (RMP)

The state machine implements a linear ramping law (+5% duty per tick, default `CONFIG_APP_RAMP_TICK_MS = 50ms`):

$$\text{Ramp Time to 100\%} = \frac{100\%}{5\% / \text{step}} \times 50\text{ ms} = 1.0\text{ second}$$

| Test ID | Test Case Name | Objective / Scenario | Input Stimulus | Expected Output / State | Execution Level |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-RMP-01** | Soft-Start Acceleration Curve | Rapid step from Speed 0 to Speed 6 (Target: 60% duty). | Slider jumped `0 -> 6` instantly | State: `MIXER_STATE_RAMPING`<br>Duty ramps: `0% -> 5% -> 10% ... -> 60%`<br>State transitions to `RUNNING` at 60% | Tier 1 (Unit)<br>Tier 3 (Renode) |
| **TC-RMP-02** | Controlled Deceleration Curve | Step down from Speed 8 (80%) to Speed 2 (20%). | Slider jumped `8 -> 2` | State: `MIXER_STATE_RAMPING`<br>Duty drops: `80% -> 75% -> 70% ... -> 20%`<br>Smooth torque reduction | Tier 1 (Unit)<br>Tier 3 (Renode) |
| **TC-RMP-03** | Mid-Ramp Target Reversal | User changes speed while motor is actively ramping (e.g., ramping to 8, but slider pulled back to 2 at 45%). | `0 -> 8`, at duty 45% slider moves to `2` | Ramping reverses direction smoothly at 45% down to 20% without torque spikes or overshoot | Tier 1 (Unit)<br>Tier 3 (Renode) |
| **TC-RMP-04** | PWM Non-Intrusive Duty Assertion | Assert hardware timer compare register matches software duty percentage. | Speed 5 selected (50% target) | Virtual PWM register at `0x40038020` reads exact 50% period without serial print reliance | Tier 3 (Renode)<br>Tier 4 (HIL) |
