# Smart-Appliance-Edge-DevOps


## architecture of whole Project 

```yaml
[ Developer Git Push ]
         │
         ▼
[ Stage 1: Containerized Toolchain ] ───► Eliminates "works on my machine"
         │
         ▼
[ Stage 2: Orchestration (Jenkins) ] ───► Automated triggers & merge gates
         │
         ▼
[ Stage 3: Static Analysis & Quality ] ──► Catches memory leaks & MISRA bugs
         │
         ▼
[ Stage 4: Smoke Simulation (QEMU) ] ───► Ultra-fast CPU/logic unit tests (<60s)
         │
         ▼
[ Stage 5: System Emulation (Renode) ] ──► Hardware-accurate peripheral & fault tests
         │
         ▼
[ Stage 6: Artifact Signing & Cloud ] ──► MCUboot cryptographic signatures & S3 storage
         │
         ▼
[ Stage 7: Physical HIL Execution ] ────► Real STM32 hardware sanity check
         │
         ▼
[ Stage 8: IaC & Fleet Observability ] ──► Automated runner provisioning & CI metrics
```

## architecture of Github Repository 
```yaml
📁 Smart-Appliance-Edge-DevOps/         
│
├── 📁 .github/                # GitHub-specific configs (or Jenkins webhooks docs)
├── 📁 .vscode/                # Shared workspace settings for C/C++ intellisense
│
├── 📁 firmware/               # The actual Embedded C Zephyr application
│   ├── 📁 src/                # C source files (main.c, threads, drivers)
│   ├── 📁 boards/             # Custom device tree overlays (.overlay) for STM32F401
│   ├── CMakeLists.txt         # Firmware build instructions
│   └── prj.conf               # Zephyr OS configuration (RTOS features enabled)
│
├── 📁 build-env/              # Stage 1 lives here
│   └── Dockerfile             # The hardened Zephyr + CMake + ARM GCC container
│
├── 📁 ci-cd/                  # Stage 2 & 3 live here
│   ├── Jenkinsfile            # The master pipeline definition
│   └── sonar-project.properties # Static analysis rules
│
├── 📁 simulation/             # Stage 4 & 5 live here
│   ├── 📁 qemu/               # QEMU helper scripts
│   └── 📁 renode/             # Virtual hardware definition
│       ├── stm32f401.repl     # Virtual peripheral memory map layout
│       └── machine_setup.resc # Script to boot the virtual board
│
├── 📁 tests/                  # Integration and System tests
│   ├── 📁 logic_tests/        # PyTest scripts for QEMU
│   └── 📁 hardware_tests/     # Robot Framework scripts for Renode
│
├── 📁 infrastructure/         # Stage 6 & 8 live here
│   ├── 📁 terraform/          # Code to spin up AWS S3 buckets and EC2 nodes
│   └── 📁 ansible/            # Scripts to configure the Jenkins server
│
└── 📁 docs/                   # "Doc-as-code" architecture decisions and runbooks
    └── architecture.md
```
